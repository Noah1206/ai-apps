# 부산 사투리 스피킹 트레이너 — MVP UX 확정안

메모 문서(`mvp_plan.md`, `에듀테킹 앱 Main Contents.md`, `에듀 테크 질문 리스트.md`,
`에듀 테크 기업.md`) 분석 결과를 하나의 실행 가능한 UX 확정안으로 통합한 문서다.
디자인은 `Design md`(Lovable 디자인 시스템)를 따른다.

---

## 1. 무엇을 만드는 앱인가 (분석 결론)

> **외국인이 부산 사투리를 듣고, 따라 말하고, AI와의 역할극에서 실제로 반응하게
> 훈련시키는 음성 기반 한국어 학습 앱.**

- 방향: Engaging-first가 아니라 **Efficacy-first**. 재미는 학습을 끝까지 가게 하는 손잡이.
- 타겟: K-콘텐츠를 좋아하는 영어권 외국인 (페르소나 Sally).
- MVP 범위: **부산 하나만**. 상황 5개(친구/식당/시장/길묻기/자기소개) + 표현 50개 + Stage 6개.
- 핵심 순간: "어? 나 방금 부산 사람 말을 알아들었어" / "나 방금 사투리로 대답했어".
- 바이럴 포인트: **AI 캐릭터와의 사투리 대화** (질문 리스트 10번 답변).
- 이 레포의 Python 연구 랩(Surface ASR, 발음 평가)은 장기적으로 이 앱의
  피드백 엔진 백엔드가 된다. 앱은 어댑터 계약으로 엔진과 분리한다
  (연구 랩의 `SurfaceASRAdapter` 패턴과 동일 철학).

## 2. 핵심 기능 하이라이트 — "사투리 AI 피드백 루프"

앱의 심장은 이 루프 하나다. 나머지 화면은 전부 이 루프를 향한 진입로다.

```text
상황 제시 (부산 포장마차, 목표 + 필수 표현 제시)
→ NPC와 음성 대화 (Step-up: 따라 말하기 → 선택형 → 자유 응답 → 상황 미션)
→ 녹음 → STT → 정답 비교 → 다차원 점수
→ AI 코치 피드백 (한 번에 하나만 교정)
→ 대화 복기 저장 → 에빙하우스 복습
```

확정 원칙 (메모 문서에서 이미 결정된 것):

1. **NPC ≠ 코치.** NPC 캐릭터는 대화만, AI 코치는 텍스트로 설명·교정만. 역할 분리.
2. **실패해도 멈추지 않는다.** 분기형 진행 — 못 알아들으면 NPC가 되묻고 다시 기회.
3. **점수는 5차원 분해.** 의미 전달 / 사투리 표현 / 발음 / 억양 / 자연스러움.
   단일 점수 금지. 피드백은 한 번에 하나만.
4. **표준어 비교는 팁으로.** 대화 화면 구석의 작은 노란 아이콘 → 탭하면 표준어/뉘앙스.
5. **사투리 강도 레벨(1~3)** 은 대화 중 텍스트로만 안내.
6. Zoom(영상통화) 모드는 **MVP 제외** — Step-up이 뼈대, Zoom은 피부.

## 3. 에듀테크 벤치마크 진단 (확정)

| 벤치마크 | 가져올 것 | 버릴 것 |
|---|---|---|
| **Speak (스픽)** | 대화 중심 화면: 채팅형 말풍선 + 하단 대형 녹음 버튼, 미션 목표 체크리스트, 턴 단위 "다시 말해보기" | 무제한 자유 대화 (목표 없는 대화는 이탈 요인 — 메모 문서 결론과 일치) |
| **ELSA Speak** | 발화 결과의 다차원 점수 시각화, 문장 내 잘된/틀린 부분 하이라이트 | 음소 단위 IPA 피드백 (Gate 2 이후 연구 영역, MVP 아님) |
| **Duolingo** | Stage 경로(잠금/추천/진행중/마스터), 데일리 복습 due, 스트릭·알림 | EXP 상점, 코스메틱, 리그전 (Efficacy-first 위배) |
| **Beelinguapp/문화형** | 표현마다 뉘앙스·문화 한 줄 설명 | 긴 문법 강의 |

결론: **화면 골격은 Speak, 진행 구조는 Duolingo 경로, 피드백 시각화는 ELSA.**

## 4. 정보 구조 (IA) — 확정

탭 3개 + 모달 플로우. (메모 문서의 화면 구조 6개를 탭으로 재배치)

```text
[탭] Home      — Today's Training, Continue, Review due 요약, 스트릭
[탭] Path      — Busan 스토리 경로: Stage 1~6 × 상황 5개 (에피소드형)
[탭] Review    — 오늘 복습할 표현 + 대화 복기(지난 대화 다시 열어 재발화)

[모달] Mission — 학습 본 화면 (듣기/따라말하기/선택형/자유응답/역할극)
[모달] Result  — 5차원 점수 + 코치 피드백 + 다시 해보기
온보딩/진단 테스트 — 첫 실행 1회 (Recommended Stage 산출)
```

스토리 진행(부산 생활 해금): 1화 부산역에서 친구 만나기 → 2화 돼지국밥 주문
→ 3화 시장 → 4화 길묻기 → 5화 자기소개. 단어가 아니라 **생활을 해금**한다.

## 5. Mission 화면 상세 (핵심 화면)

- 상단: 상황 카드(목표 + 필수 표현 칩 2~3개, 사용하면 체크됨)
- 중앙: 대화 스레드 — NPC 말풍선(크림 카드, 캐릭터 이름), 유저 발화(차콜)
- 우상단: 작은 노란 팁 아이콘 → 표준어 비교/뉘앙스 바텀시트
- 하단: 풀-필(9999px) 녹음 버튼 1개. 누르고 말하기. 재생/느린 재생 보조 버튼
- 실패 시: NPC가 "뭐라꼬? 다시 말해봐라" 되묻기 → 같은 턴 재시도

## 6. 디자인 적용 규칙 (Design md → 앱 토큰)

- 배경 `#f7f4ed`, 텍스트 `#1c1c1c`, 보조 `#5f5f5d`, 보더 `#eceae4`
- 그림자 대신 보더로 카드 구분. 카드 radius 12, 버튼 6, 녹음 버튼 9999
- 다크 버튼: `#1c1c1c` bg + `#fcfbf8` 텍스트 + 인셋 섀도
- 웨이트 2개: 400 본문 / 600 헤딩. 헤딩은 타이트한 자간
- 유일한 유채색 예외: 표준어 팁 아이콘(작은 노란색) — 메모 문서 명시 사항
- 폰트: Camera Plain 라이선스 없으므로 시스템 폰트로 시작, 추후 유사 휴머니스트
  산세리프(예: Instrument Sans)로 교체

## 7. 기술 스택 (확정, mvp_plan §17 그대로)

- 앱: **React Native + Expo (expo-router, TypeScript)** — iOS/Android 크로스.
  네이티브 빌드 필요 시 `npx expo run:ios`가 Xcode 프로젝트를 생성한다.
- 백엔드: Supabase (로그인/진도/점수/복습 일정) — MVP 후반 연결
- STT/피드백: 외부 STT API → 정답 비교 → 규칙 기반 + LLM 보조.
  앱 쪽은 `FeedbackEngine` 인터페이스로 추상화해 두고, 장기적으로 연구 랩의
  Busan adapter ASR로 교체한다.
- 원어민 음성: Audio Lab 파이프라인 산출물(느린/자연 2벌) 사용. 그 전까지는
  기기 TTS placeholder.

## 8. MVP에서 하지 않는 것 (재확인)

3D 마을, 타이쿤, 다지역, 랜덤 매칭, 커뮤니티, 랭킹, 욕쟁이 모드, 결제,
문법 강의, 번역기, Zoom 영상통화 모드, 카메라 분석.
